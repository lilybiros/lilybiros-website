Code

I run my home lab on a UGREEN NAS DXP2800, configured in RAID 1 with HDD and SSD drives. It hosts Immich, Tailscale, Pihole, Vaultwarden, Home Assistant and AdGuard, each in its own Docker container, with remote access from anywhere in the world. I built all of it as a communicator with no coding background.
